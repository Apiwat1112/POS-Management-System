# 🚀 Installation Guide

## 📥 Download Project

ดาวน์โหลดโปรเจคจาก GitHub:
https://github.com/Gundamlnwza191/ProJ-ITMI1210-Designing-Web-APIs-with-Node.js-P2T2-FINAL

1. กดปุ่ม **Code**
2. เลือก **Download ZIP**
3. แตกไฟล์ ZIP ลงในเครื่อง

---

## 📂 เข้าโฟลเดอร์โปรเจค

เปิด Terminal / Command Prompt / PowerShell แล้วพิมพ์:

```bash
cd ProJ-ITMI1210-Designing-Web-APIs-with-Node.js-P2T2-FINAL
```

---

## 📦 ติดตั้ง Dependencies

โปรเจคนี้ใช้ Node.js ต้องติดตั้ง package ก่อน:

```bash
npm install
```

---

## 🗄️ Database

ภายในโปรเจคมีไฟล์ **Database (JSON)** เตรียมไว้แล้ว

📁 อยู่ในโฟลเดอร์:

```
/data/
```

ไฟล์ตัวอย่าง เช่น:

* products.json
* employees.json
* members.json
* sales.json

👉 สามารถนำไฟล์เหล่านี้ไป import เข้า MongoDB ได้ทันที

---

## ▶️ รันระบบ

เริ่มทำงานด้วยคำสั่ง:

```bash
npm start
```

หรือ

```bash
node app.js
```

---

## 🌐 เข้าใช้งานระบบ

เปิด Browser แล้วเข้า:

```
http://localhost:3000/
```

ระบบจะพร้อมใช้งานทันที 🎉
